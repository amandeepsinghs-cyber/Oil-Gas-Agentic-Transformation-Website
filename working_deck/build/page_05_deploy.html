Where will the agents be deployed?

Wherever the work happens: one front door for everyone, and the agent goes to the screen or the process where it is needed.

01
Gemini Enterprise
The front door: every persona finds and uses their agents in one place.
02
Custom applications
Purpose-built apps, for example on Cloud Run, where a chat window is not enough.
03
Inside existing systems
Agents surfaced in the monoliths people already use: ERP, maintenance, historian, laboratory.
04
Inside your processes
Headless agents triggered by an event or schedule; they prepare the work and hand it to a person.
