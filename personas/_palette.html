1 · Core colours

Official values from the Google Cloud brand site. Live is what the browser actually computes for that token on the profile page right now.

2 · What each colour is allowed to mean

Colour on this page is load-bearing, not decorative. These are the only jobs a hue is permitted to do — if a colour appears anywhere else, that is a defect.

3 · Text contrast

WCAG 2.1 contrast ratio for every text-on-surface pair the page actually uses. AA needs 4.5:1 for body text and 3:1 for large text (≥24px).

4 · Gradient discipline

The brand permits four primary gradients: Red-Yellow, Yellow-Green, Green-Blue, Blue-Purple. It explicitly forbids gradients as backgrounds, gradients on text, and tints or shades of gradient colours.
